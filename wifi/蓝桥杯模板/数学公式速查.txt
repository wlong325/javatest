蓝桥杯单片机数学公式速查
========================

一、常用单位换算
--------------
1 m = 100 cm = 1000 mm
1 L = 1000 mL = 1000 cm^3
1 cm^3 = 1 mL
1 m^3 = 1000 L

如果题目给尺寸单位是 cm，算出来的体积单位通常是 cm^3，也就是 mL。
如果题目要求 L，最后除以 1000。

二、线性映射/标定
----------------
把输入 x 从区间 [x1, x2] 映射到输出 y 的区间 [y1, y2]：

y = y1 + (x - x1) * (y2 - y1) / (x2 - x1)

常用于：
1. 电压映射重量。
2. ADC 映射实际物理量。
3. 两点标定。
4. 温度补偿。

C 代码注意：
如果都用 int，先乘后除，避免小数提前被截断。
例如：
y = y1 + (long)(x - x1) * (y2 - y1) / (x2 - x1);

三、ADC/DAC 常用公式
------------------
PCF8591 是 8 位，数字量范围 0~255。

ADC 转电压，单位 mV：
voltage_mv = adc_value * 5000 / 255

电压转 DAC 数字量：
dac_value = voltage_mv * 255 / 5000

如果显示 x.xx V：
整数位 = voltage_mv / 1000
小数第一位 = voltage_mv / 100 % 10
小数第二位 = voltage_mv / 10 % 10

四、百分比
----------
百分比 = 当前值 * 100 / 总值
剩余百分比 = 剩余值 * 100 / 总值

注意：
如果总值可能为 0，必须先判断，避免除以 0。

五、长方体/圆柱体/球体体积
------------------------
长方体体积：
V = L * W * H

圆柱体体积：
V = PI * r * r * h

球体体积：
V = 4.0 / 3.0 * PI * r * r * r

半球体体积：
V = 2.0 / 3.0 * PI * r * r * r

注意：
如果 L/W/H/r 单位是 cm，V 单位就是 cm^3，也就是 mL。

六、球缺/球冠体积
----------------
球缺高度 h，球半径 r，球缺体积：
V = PI * h * h * (3 * r - h) / 3

适用范围：
0 <= h <= 2r

如果球形容器底部到液面高度是 h：
液体体积 V_liquid = PI * h * h * (3 * r - h) / 3

如果要求剩余空间：
V_total = 4.0 / 3.0 * PI * r * r * r
V_empty = V_total - V_liquid

如果 h > 2r，说明液位超过球直径，应该按满球处理。
如果 h < 0，应该按空处理。

七、圆柱卧放液体截面积
--------------------
这个比较少考，但如果圆柱横放会用到。
半径 r，液位高度 h，0 <= h <= 2r：

截面积 A = r*r*acos((r-h)/r) - (r-h)*sqrt(2*r*h - h*h)
体积 V = A * L

注意：
C51 标准库不一定方便用 acos/sqrt，比赛中若题目复杂到这里，优先看题目是否给了简化公式。

八、梯形/三角形面积
------------------
矩形面积：
S = a * b

三角形面积：
S = a * h / 2

梯形面积：
S = (a + b) * h / 2

常用于不规则容器截面、分段液位计算。

九、频率/周期/计数
----------------
频率 f，周期 T：
f = 1 / T
T = 1 / f

如果 T 单位是秒，f 单位是 Hz。
如果 T 单位是 ms：
f = 1000 / T_ms
如果 T 单位是 us：
f = 1000000 / T_us

NE555 频率测量常用 1 秒闸门：
1 秒内计数值 count，就是频率 Hz。

如果闸门时间不是 1 秒：
f = count * 1000 / gate_ms

十、超声波测距
------------
常温下声速约 340 m/s。
距离 = 时间 * 声速 / 2

如果时间单位是 us：
distance_cm ≈ time_us * 0.017

温度补偿声速：
v = 331.4 + 0.6 * temperature_c，单位 m/s

distance_cm = time_us * v / 20000

解释：
声波往返，所以除以 2；us 转 s、m 转 cm 后合并成 /20000。

十一、DS18B20 温度
----------------
DS18B20 原始值通常是 16 位补码，低 4 位是小数。

如果只要整数温度：
temperature = raw >> 4

如果要保留一位小数：
temperature_x10 = raw * 10 / 16

负数要先按补码处理，模板里已有 DS18B20_ToIntC() 可参考。

十二、分段线性插值
----------------
如果题目给多个标定点，例如：
0kg 对应 V0
5kg 对应 V5
10kg 对应 V10

测量值 x 落在哪一段，就用哪一段的两点公式：
y = y1 + (x - x1) * (y2 - y1) / (x2 - x1)

常用于称重、温度补偿、传感器非线性近似。

十三、变化趋势判断
----------------
连续增大：
x0 > x1 && x1 > x2 && x2 > x3

连续减小：
x0 < x1 && x1 < x2 && x2 < x3

相邻变化过大：
abs(x0 - x1) > threshold

C51 没有必要用 abs() 时，可以写：
if(x0 > x1) diff = x0 - x1;
else diff = x1 - x0;

十四、常用显示拆位
----------------
显示整数 value：
万位 = value / 10000 % 10
千位 = value / 1000 % 10
百位 = value / 100 % 10
十位 = value / 10 % 10
个位 = value % 10

高位灭零示例：
如果 value < 1000，千位显示 SEG_BLANK。
如果 value < 100，百位显示 SEG_BLANK。
如果 value < 10，十位显示 SEG_BLANK。

显示一位小数，例如 value_x10 = 123 表示 12.3：
十位 = value_x10 / 100
个位带小数点 = value_x10 / 10 % 10 + 16
小数位 = value_x10 % 10

十五、C51 计算注意事项
--------------------
1. int 在 C51 里通常是 16 位，范围大约 -32768~32767。
2. 体积、乘法、平方、立方容易溢出，必要时用 long 或 float。
3. 整数计算会截断小数，想保留小数可以把结果扩大 10 倍或 100 倍。
4. 先乘后除可以减少精度损失，但要注意乘法溢出。
5. float 能用但代码体积会变大，比赛中简单显示优先用整数放大法。

十六、PI 取值
------------
一般题目如果没有特殊要求：
PI = 3.14

如果要减少 float，可以用整数近似：
PI_X100 = 314

例如圆面积扩大 100 倍计算：
area_x100 = 314 * r * r
area = area_x100 / 100
